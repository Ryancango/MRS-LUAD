# Code availability

Analysis scripts required to reproduce the main computational analyses are available in this repository. The repository contains curated scripts for discovery-cohort preprocessing, WGCNA, GO enrichment, machine-learning model comparison, MRS score calculation, single-cell MRS scoring, scFEA-derived metabolic flux analysis, pseudotime inference, CellChat visualization, T-cell exhaustion analysis and pan-cancer prognostic assessment.

Large public expression matrices, downloaded GEO/TCGA/Xena files and intermediate R objects are not deposited in the repository because of file size and redistribution considerations, but can be regenerated from the public datasets listed in `metadata/datasets_used.tsv`.

For manuscript submission, use the following concise statement after replacing the repository URL if needed:

> The analysis code used in this study is available at [GitHub repository URL]. The repository contains curated scripts for bulk transcriptomic discovery, WGCNA, machine-learning model construction, MRS score calculation, single-cell metabolic flux analysis, pseudotime inference, cell-cell communication analysis and pan-cancer validation. Large public expression matrices and intermediate R objects are not included but can be regenerated from the public datasets described in the Data availability statement.
